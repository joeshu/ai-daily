## 🔥 Arena.ai 上线 Agent Mode：让前沿模型完成真实任务并参与竞技排名
**来源**: lmarena.ai(@lmarena_ai)

- Agent Mode 支持 GPT-5.5、Claude Opus 4.7、Gemini 3.1 Pro 等模型通过搜索、代码沙箱、图像生成等工具完成深度研究、建站、调试等复杂任务。
- 用户会话数据用于排行榜排名，采用因果推断方法，基于任务成功、可控性、错误恢复、用户赞扬/投诉、工具幻觉5个信号评估 agent 能力。
- 配套发布方法论博客，详细解释排行榜技术原理。

Arena.ai 将众包评测从纯对话扩展至 agent 场景，为前沿模型提供贴近真实使用的竞技场。
